# Convergent Intelligence 2026

A static, GitHub Pages-ready website for **Convergent Intelligence: AI Hardware Co-Design and the Future of Computing**.

## Publish with GitHub Pages

1. Create a GitHub repository and upload these files to its default branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the default branch and the **/(root)** folder, then save.

GitHub will publish the site at `https://YOUR-ACCOUNT.github.io/YOUR-REPOSITORY/`.

## Content to update

The website intentionally marks registration, venue, speaker, organizer, partner, and program content as coming soon. Search for “Coming soon”, “to be announced”, or “to follow” to replace those placeholders.
